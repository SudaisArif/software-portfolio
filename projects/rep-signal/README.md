# REP SIGNAL — production and review workflow

Python orchestration, SQLite job state, local review dashboard, rendering interfaces and external-service adapters for a fitness-media workflow. Review decisions bind to exact revisions and artifact hashes; publishing remains disabled without explicit configuration and approval.

```sh
python3 studio.py --help
python3 studio.py init
python3 studio.py status
```

This portfolio distribution contains code and an offline sample brief. Private account configuration, credentials, finished media, stock footage, local narration models and runtime data are excluded. Rendering requires FFmpeg and the renderer dependencies plus appropriately licensed assets. Integrations require separate credentials. No published videos or production-scale service are claimed. Some original integration/render tests require assets not distributed here.
