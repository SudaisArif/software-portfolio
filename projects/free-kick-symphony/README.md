# N5 — Free Kick Symphony

Write a melody, perform it through a free kick, and keep the shots you want to use in your composition. The sound is generated by custom physical strings, moving delay, air loss, stereo placement and damped feedback ambience. No commercial recordings or generated images are bundled.

## Open

Double-click `Start.command`, or run:

```sh
python3 src/serve.py --open
```

Open http://127.0.0.1:8765. Refresh an existing tab after updating. Browser playback requires no Python audio packages. Use headphones. If port 8765 is occupied, reuse that server or choose `--port 8766`.

## Write → perform → keep

1. Choose a preset or **Write my own melody**. Click the piano grid, import MIDI, or type note names such as `A3 C4 E4 - G4 E4 D4 C4`. `-` is a rest; `C4+E4+G4` is a chord. Each space advances one selected grid step. All notes are plucked attacks; **Decay** controls how long they ring.
2. Set **Composition · bars**, BPM (60–180), and 1, 2 or 4 bars. The complete phrase fits those bars. Changing the bar length stretches the phrase; changing the grid resolution changes the editing grid, not existing notes. Scale highlights guide writing without changing pitches. **Free flight** retains the original distance/power-dependent timing.
3. Choose **Stable · melody** for pitched layers or **Moving · Doppler** for pitch motion. Shape power, curl, loft and distance; aim at the goal and take the shot. Sound sliders are live; notes, timing and geometry apply to the next shot. A short visual run-up occurs before audio begins.
4. Wait for the release to finish, name the result, then **Keep this shot**. Taking another shot replaces the unkept audition. Stopping early discards that audition; it never silently saves a different full performance. Kept shots remain untouched.
5. Export **WAV** for audio, **Shot** for the exact settings, or **MIDI** for underlying notes. **Save session** backs up all kept shots. **Open session** accepts an individual shot, a version 2 session, or an earlier version 1 session. Browser storage keeps up to 200 saved shots; download backups for portability.

The grid has a two-octave view; use **Keyboard** to reach other pitches. The note-count control can select fewer events without deleting the full editable bank. Editing a reduced selection replaces that bank with the newly edited notes.

Power changes excitation strength and brightness. Curl moves the sound in stereo. Loft adds a brightness/ambience contour. Distance changes attenuation and air loss. Moving-pitch mode adds propagation-delay pitch motion. Decay, brightness, pluck position, stadium mix and register remain directly adjustable.

## Use your shots in Assignment 10

Each WAV starts at its musical time zero and includes the release tail. In Composition mode, start the next phrase after `bars * 4 * 60 / bpm` seconds, even while the previous release is ringing. The shot JSON includes this duration, frame count, sample rate, key guide, exact notes, seed, expression settings, trajectory and live automation. A key guide is not an inferred key or automatic harmonization. MIDI exports the score and tempo, not the custom sound, release envelope, effects or automation; exported MIDI notes use a fixed 0.45-beat gate.

Install the Python composition dependencies if needed:

```sh
python3 -m pip install -r src/requirements.txt
```

Arrange a downloaded shot/session with Pyquist:

```sh
python3 src/arrange.py --session /path/to/N5-session.json --order 1,2,1,3 --out outputs/shot_sequence.wav
```

`--order` uses positions in the saved file, starting at 1; omit it to use saved order. `--repeat 2` repeats the sequence. The script re-renders each saved shot, places the phrases with `pq.Score`, overlaps release tails, and writes stereo 48 kHz PCM16 audio plus a placement manifest. It preserves each shot's timing; use a common BPM for a consistent track. This is composition material, not a complete final-project submission or a claim of four techniques by itself.

The original 28-second sketch remains available in the app and can be regenerated with:

```sh
python3 src/compose.py
```

It demonstrates the instrument alongside Python FM bass and subtractive percussion. The final piece still needs original development, 60–120 seconds of music, the required course techniques/Pyquist work, visual and write-up.

## Assignment 9 submission

Review `TECHNICAL.md` before recording your own narrated 2–5 minute video. The three buttons under **Three ways to play** load the prepared examples directly: muted melody, ringing chords, and moving reference. Click an example, then **Take the shot**. Notes, timing, pitch mode and sound settings are all included; Demo 1 also fills the written-note entry and selects Quarter notes. A fresh browser starts on Demo 1; an existing browser preserves its current draft and saved shots. Examples are supplied separately from your kept performances, so refreshing never duplicates them in your session. Keep a completed performance when you want to export it. You can also import `src/assets/demo-session.json` using **Open session**, then use each saved row's **Edit** button. Recording scripts are kept outside the submission ZIP.

```sh
python3 src/tools/package.py --video /path/to/your-recording.webm
```

Without `--video`, the tool creates `N5-source-bundle.zip`, which is a source backup and **not a complete submission**. The tool checks headings, video length/audio and ZIP size; it cannot verify your explanation or three demonstrations.
